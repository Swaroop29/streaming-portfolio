# streaming-portfolio

A streaming-style personal portfolio: visitors pick a profile ("Recruiter", "Hiring manager", "Engineer", "Just browsing"), then browse rows of cards for your experience, projects, skills and more. You fill it in by giving this repository and your resume to any AI assistant.

- All your content lives in one file, `profile.js`.
- Fully readable by search engines and AI agents without JavaScript (static HTML, `llms.txt`, `sitemap.xml`, structured data).
- Works on phones and desktops, with automated tests for layout, accessibility and content.
- No tracking by default. MIT licensed.

## No coding? Start here

1. Open an AI assistant that can create files and run code (Claude, Claude Code, Codex or similar) and give it this repository's link and your resume or LinkedIn text.
2. Paste: *"Read AGENTS.md and build my portfolio from my resume. Do not invent anything. Then ask me how I want to publish it."*
3. It builds the site, gives you one zip file, and asks where to publish. The recommended option is **Vercel**: drag the zip onto vercel.com/drop and your site is live in seconds. The link is temporary until you click **Claim Project** and sign in (a free account, Google sign-in works), then it is yours permanently.

You never need to run a command yourself.

## Make your own in 3 steps (if you are comfortable with GitHub)

1. **Use this template.** Click **Use this template** on GitHub (or fork it) to create your own copy.
2. **Give it to an AI.** Open an AI coding assistant that can edit a repository (Claude Code, Codex, Cursor, Copilot agent and similar), point it at your copy, attach your resume or LinkedIn export, and paste:

   > Read AGENTS.md in this repository and follow it. Build my portfolio from the attached resume and the links below. Do not invent anything. Leave a field empty if I did not give it to you. Run the build, check and tests, then tell me what you left blank.
   >
   > My LinkedIn: ...  My GitHub: ...  Where I will host it: ...

   No coding assistant? Open `profile.js` in any editor and replace the sample data by hand. Every field is commented.
3. **Publish it.** Easiest: run `npm run package` and drag `publish.zip` onto [vercel.com/drop](https://vercel.com/drop). Or connect your repo to Cloudflare Pages, Netlify or GitHub Pages with build command `npm run build` and output directory `.`. Review the result and fix anything the AI got wrong before you share the link.

## Commands

| Command | What it does |
| --- | --- |
| `npm install` | Install the dev tools (once) |
| `npm run build` | Generate `index.html`, `llms.txt`, `robots.txt`, `sitemap.xml` from `profile.js` |
| `npm run check` | Validate your content and flag leftover sample data |
| `npm test` | Unit and content tests |
| `npm run single` | Build ONE self-contained `index.html` (easy to preview in a chat and to drag onto a host) into `publish/` and `publish.zip` |
| `npm run package` | Build and collect just the publishable files into `publish/` and `publish.zip` |
| `npm run e2e` | Browser tests (needs `npx playwright install`) |
| `npm run themes` | List the available designs (themes) and who each suits |
| `npm run og` | Regenerate the share-card image from your name and tagline |

To preview locally: `npx http-server . -p 4173`, then open http://localhost:4173.

## Tips

- Phone numbers are hidden by default. Add one in `contact.phones` only if you want it public.
- Analytics is optional: set `site.analytics.goatcounter` to your GoatCounter code to enable it.
- The sample person ("Alex Rivera") is fictional. `npm run check` fails while any sample data is left.

## How it is organised

- `profile.js`: your content (the only file you normally edit)
- `core/`: shared code (validation, SEO files, the plain-text version for AI agents, one-file packaging)
- `themes/`: the designs. `netflix` is bold and playful (profile picker, rows of cards). `shelves` is a dark app-like look with a side menu, a hero banner and pop-up cards. `editorial` is calm and typographic (one reading column, no JavaScript). Run `npm run themes` to see them, and set `site.theme` in `profile.js` to choose. Some designs (`neon-coast`) look best with generated pictures: use an AI that can generate images, or run `npm run image-prompts` and make them in any image tool. Missing a look? Ask your AI for it: `THEMES.md` is the recipe it follows to build a new design, and the tests check every design automatically.

Files like `index.html`, `style.css` and `script.js` in the repository root are generated by `npm run build`. Edit the content or the theme folder, not those copies.
